Overview

Glossary

Every term in the palace, defined and linked.

One alphabetized reference for the whole MemPalace vocabulary — the spatial model (wings, rooms, drawers, closets, hallways, tunnels), the retrieval stack (hybrid BM25 + vector, HNSW, the L0–L3 wake-up layers), the ingestion machinery (AAAK dialect, incremental ingest, sweeps, entity disambiguation), and the cross-cutting principles (local-first, BYOK, privacy by architecture). Each definition ends with a → pointer to the page that covers it in depth.

A

AAAK Dialect
A structured symbolic summarization format that extracts entities (people), topics (key phrases), quotes (5–55 char snippets), emotional tone codes (up to 3 per line, e.g. vul+joy), and importance flags (ORIGIN, CORE, PIVOT) into pipe-separated lines any LLM can scan in a single pass — without decompression. It is lossy by selection, never by destruction: the drawers still hold the verbatim text. → AAAK Dialect & Closets
Agent Personas
Names a user has assigned to the AI agents they converse with (Echo, Sparrow, Claude-instance-2). Tier 2 LLM corpus-origin detection extracts them, and candidates matching a persona name are reclassified out of the people bucket into agent_personas to prevent false family/relationship inference. → Entity System
as_of (temporal query)
A knowledge-graph query parameter returning only facts valid at a specified instant. A date-only value like as_of=2026-01-15 normalizes to T00:00:00Z, and the comparison logic handles both legacy date-only values and canonical UTC datetimes. → Temporal Knowledge Graph
auto_save
Boolean config flag (hooks.auto_save, default True) that gates all Stop and PreCompact hook functionality. When False, hooks pass through silently and do no background filing. → Hooks & Auto-save

B

BaseBackend
The per-palace factory contract (RFC 001): owns get_collection, close_palace, health, and optional detect hooks. Lightweight on construction (no I/O); connection is deferred to get_collection and it is thread-safe for concurrent multi-palace access. → Storage Backends
BaseCollection
The abstract per-collection interface every backend must implement: add, upsert, query, get, delete, count, and optional update/health/close. The read/write contract consumed by miners, searchers, and repair tools. → Storage Backends
BCP 47 Language Tag
The standardized, case-insensitive language code (RFC 5646). MemPalace normalizes via _canonical_lang() so PT-BR, pt-br, and Pt-Br all resolve to the same locale file. → Internationalization
BM25 (Okapi-BM25)
The probabilistic keyword-matching algorithm that scores documents by term frequency and inverse document frequency (IDF), tuned with k1=1.5 and b=0.75. In MemPalace, IDF is computed over the candidate set (not the whole corpus) and BM25 also powers the FTS5 fallback when the vector index is unusable. → Search & Retrieval
BYOK (Bring Your Own Key)
The policy for external LLM providers: they are supported only when a user explicitly supplies credentials, and are never enabled silently or by default. Local inference (Ollama/LM Studio/llama.cpp) needs no key. → LLM Integration

C

Cache Invalidation
Detection of external writes to chroma.sqlite3 via inode + mtime checks, forcing a ChromaDB client/collection rebuild so the MCP server never serves results off a stale HNSW index. → MCP Server & Tools
Candidate strategy
The policy for gathering candidates before hybrid re-rank: vector (default) takes the top n_results*3 from HNSW, while union also pulls BM25-only candidates from SQLite FTS5 to widen the re-rank pool. → Search & Retrieval
Closet
A searchable index record in the mempalace_closets collection holding compact topic·entity·quote pointer lines that reference one or more drawers. Built during mining (extract→pointer→pack, greedily up to 1,500 chars) and scanned first during search to decide which verbatim drawers to fetch. → The Palace Model
Closet boost
A ranking signal: when a query matches a closet, the effective cosine distance of drawers from its source file is reduced by 4–40% (rank-based, clamped to [0, 2]). Closets are boosts, never gates, so a weak closet can only help a result, never hide one. → Search & Retrieval
Closet packing
Atomic grouping of pointer lines into fixed-character closets that never split mid-topic, packed greedily up to CLOSET_CHAR_LIMIT=1500; a re-mine does a full rebuild to avoid orphaned closets. → AAAK Dialect & Closets
COCA Content-Word Filter
A frozenset of ~600 common English words (code, phase, brutal, line, note) that appear capitalized but are not proper nouns. It blocks false-positive entity detection on sentence-start words; multi-word candidates intentionally bypass it so compounds like Claude Code survive. → Entity System
Combining Mark
A non-spacing diacritical mark (Unicode Mc/Mn), e.g. a Hindi matra (ा) or Arabic vowel. Python's \b word boundary ignores them and truncates names, so MemPalace uses script-aware lookaround boundaries instead. → Internationalization
Confidence score
A per-triple float (default 1.0) recording certainty in a knowledge-graph fact. Stored but not yet used in ranking; reserved for future fact-assessment and conflict resolution. → Temporal Knowledge Graph
Corpus-Origin Detection
A two-tier system that decides whether a corpus is AI-dialogue or human narrative. Tier 1 is a fast brand-term regex heuristic (always on, no API); Tier 2 is an optional LLM pass that confirms and extracts platform identity and agent-persona names — merging into, never overwriting, the heuristic. → Entity System
Cosine distance
The vector-similarity metric in the [0, 2] range used by ChromaDB's HNSW index (0 = identical, 2 = opposite). MemPalace reads it as an absolute distance, not relative-to-max, so rankings stay stable as candidates are added or removed. → Search & Retrieval
Crash-safe upsert
The pattern of using deterministic drawer IDs (e.g. sweep_SESSION_UUID) so a re-upsert idempotently dedupes on reruns, making sweeps and other ingest paths resumable after a failure. → Repair, Sync & Maintenance

D

Detached Subprocess
Hook-spawned mines run as fully detached processes (POSIX start_new_session or Windows process groups), so the hook returns immediately while background filing continues. → Hooks & Auto-save
Diary
A dated journal entry or conversation log mined from a transcript. Its timestamp (ISO YYYY-MM-DD) is taken from the filename, frontmatter, content, or mtime and stored as content_date, enabling temporal grouping. → The Palace Model
Disambiguation Context
For ambiguous words that double as common English (ever, grace, may, Rose), EntityRegistry._disambiguate() weighs surrounding context against person-context patterns (said, with, 's) and concept-context patterns (have you, if you, would) to adjust the classification. → Entity System
Drawer
A single chunk of verbatim source text (~800 chars), immutable once written and never summarized or paraphrased. Identified by drawer_WING_ROOM_SHA256(source-file+chunk-index), it is the atomic unit that is queried, ranked, and returned in search results. → Project Mining
Drawer sweep
Timestamp-coordinated, idempotent message-level ingestion that catches individual messages missed by file-level chunking; a cursor and deterministic IDs let it resume cleanly after a crash. → Conversation Mining
Drawer-grep enrichment
When a closet-boosted match spans multiple chunks in one source file, the searcher selects the chunk with the highest keyword overlap and returns it plus its immediate neighbors for context. → Search & Retrieval
Dynamics
The living-connection math applied to hallways and tunnels: Hebbian potentiation (strength grows on co-access), Ebbinghaus decay (fades over time), and the Cepeda spacing effect (stability grows on spaced reinforcement), so connections rank by real salience. → The Palace Model

E

Effective distance
The cosine distance after closet boost is applied: max(0.0, min(2.0, raw_dist - boost)), kept inside the valid cosine range. → Search & Retrieval
Embedding / Embedding Function (EF)
A ChromaDB-compatible callable returning vector embeddings. MemPalace offers two: minilm (384-dim, English-only, faster, ~30 MB) and embeddinggemma (384-dim via Matryoshka truncation, multilingual, ~300 MB default, 0.88 cross-lingual cosine similarity). → Internationalization
Emotion Codes
Short abbreviations mapping emotional tone (vul=vulnerability, joy=joy, fear=fear…) extracted from content keywords or metadata; up to 3 per AAAK line, helping LLMs prioritize emotionally significant moments. → AAAK Dialect & Closets
Entity disambiguation
Identifying person/project/concept nodes by a lowercase-slugified entity_id so the registry and fact-checker can detect duplicates and confusion, and the knowledge graph enforces deterministic lookups via that slug. → Entity System
Entity Stoplist
A hardcoded set of 50+ words that look like proper nouns but are usually sentence-starters (The, When, User) or weekday/month names — filtered during entity extraction so fake entities don't clutter closet pointers. → AAAK Dialect & Closets
EntityRegistry
The persistent ~/.mempalace/entity_registry.json store with three tiers — onboarding (user-confirmed), learned (high-confidence detections), and wiki (Wikipedia-researched, local-only by default). Tracks aliases, ambiguous flags, and relationship metadata. → Entity System
Exchange pair
One user turn (prefixed >) plus the AI response that follows — the default chunking unit in conversation mining, preserving Q+A semantics rather than arbitrary character boundaries. → Conversation Mining
Extract mode
A conversation chunking strategy: exchange (default) preserves Q+A structure, while general uses heuristic keyword matching to extract five memory types (decisions, preferences, milestones, problems, emotional). → Conversation Mining
Extraction-cap guard
A repair safety check (repair.py::check_extraction_safety) that aborts a rebuild when the extracted drawer count falls short of the SQLite ground-truth count, preventing silent data loss. → Repair, Sync & Maintenance

F

Fact-checking
Offline verification of text against the entity registry (edit distance ≤ 2) and the knowledge graph (relationship mismatch, stale facts). Purely local, no API, zero cost. → LLM Integration
FTS5 (Full-Text Search)
SQLite's full-text index that backs BM25 keyword search and the graceful BM25-only fallback. It can drift after many collection deletes; repair.py::_vacuum_and_rebuild_fts5 atomically rebuilds it without touching row data. → Repair, Sync & Maintenance

G

Gitignore-aware sync
sync.py shares the GitignoreMatcher infrastructure with miner.py, so files excluded from mining are also removed from the palace during sync if they later become gitignored. → Repair, Sync & Maintenance

H

Hall detection
Content-type categorization (emotional, technical, family…) from keyword scoring across the first ~3,000 chars. Rooms organize by topic; halls organize by feeling/type. → Project Mining
Hallway
A within-wing connector materializing entity-pair co-occurrence: if two entities appear together in 2+ drawers in the same wing, a hallway records the pair, count, and rooms. Persisted in hallways.json with a symmetric (sorted-pair) ID so re-computation upserts rather than duplicates. → The Palace Model
Held-out evaluation
A clean train/test split: hybrid_v4 is tuned on 50 dev questions and validated on 450 previously unseen questions (98.4% R@5) to measure honest generalization, not teaching-to-the-test. → Benchmarks
HNSW (Hierarchical Navigable Small World)
The approximate-nearest-neighbor vector index inside ChromaDB that powers semantic retrieval. Its element count can drift from the SQLite row count (capacity drift / divergence), signalling corruption; MemPalace probes for this and falls back to BM25 rather than risk a segfault. → Storage Backends
Hook
A JSON-over-stdin/stdout integration point (session-start, stop, precompact) that lets Claude Code and Codex harnesses trigger background auto-save without interrupting the chat. → Hooks & Auto-save
Hybrid ranking / hybrid search
A two-stage retrieval: semantic top-50 candidates from the vector index, then a convex re-score of 0.6 × vec_sim + 0.4 × bm25_norm plus closet boost and temporal proximity. Lifts raw recall from 96.6% to 98.4% R@5. → Search & Retrieval

I

Idempotent ingest / Idempotency
Re-mining the same file produces deterministic drawer IDs (source_file + chunk_index + SHA-256), so a re-run upserts the same rows instead of creating duplicates; mtime-based detection re-mines only changed files. → Project Mining
Idempotent init
mempalace init yields the same output on re-run by filtering out MemPalace's own artifacts (entities.json, mempalace.yaml) from corpus-origin samples, so detection doesn't drift. → CLI & Onboarding
Idle Auto-Exit
A daemon watchdog that exits the MCP process after MEMPALACE_MCP_IDLE_HOURS (default 8h) with no requests, releasing ChromaDB file handles — important on Windows. → MCP Server & Tools
Importance Flags
Binary metadata tags — ORIGIN (founding moment), CORE (identity pillar), PIVOT (turning point), SENSITIVE (private) — extracted from content keywords or zettel metadata to signal foundational or sensitive drawers. → AAAK Dialect & Closets
Incremental-only invariant
Maintenance appends new data or deletes explicitly-marked corrupt entries, but never overwrites existing correct data — a crash mid-operation leaves intact rows untouched. → Repair, Sync & Maintenance
Incremental state
A per-(palace, diary-dir) file tracking content hash and entry count, used to skip unchanged diary files and detect in-place edits without re-ingesting whole days. → Conversation Mining
Input validation sanitizers
Functions like sanitize_name(), sanitize_content(), and sanitize_kg_value() that enforce safe character sets, length bounds, null-byte rejection, lone-surrogate stripping, and path-traversal prevention at the API boundary. → Security & Privacy
Invalidation (KG)
Closing a fact by setting its valid_to date. The original triple is updated, not deleted, so the audit trail and time-travel queries are preserved. → Temporal Knowledge Graph

J

JSON-decode resilience
Multi-strategy parsing of LLM responses: raw JSON first, then extraction from markdown backticks, then a scan for braced/bracketed payloads. Only if all strategies fail is the batch skipped with an error recorded. → LLM Integration

K

Knowledge Graph (temporal KG)
A SQLite-backed temporal entity-relationship graph storing subject→predicate→object triples with valid_from/valid_to dates for entity-first, time-aware reasoning. → Temporal Knowledge Graph

L

L0–L3 Wake-up Stack
Four memory layers injected on demand: L0 (user identity from ~/.mempalace/identity.txt), L1 (essential story auto-generated from the highest-importance drawers), L2 (on-demand wing/room retrieval), and L3 (deep semantic search). L0+L1 cost ~600–900 tokens; L2/L3 add context only when needed. → System Architecture
LLM endpoint validation
Rejection of non-HTTP(S) schemes (file://, ftp://…) in LLM_ENDPOINT so a misconfiguration can't exfiltrate local files through a rogue endpoint. → Security & Privacy
LLM rerank
An optional third retrieval pass: top-K sessions plus the question go to Claude Haiku, which promotes the single most relevant session to rank 1 (leaving the rest unchanged), pushing recall to ≥99%. → Benchmarks
Local-first principle
LLM assistance and embedding default to user-hosted inference on localhost (offline, no API). External providers are supported only via explicit BYOK and are never enabled silently. → LLM Integration
Lossy Summarization
AAAK selects key signals from content rather than compressing it, yet preserves 100% recall because the drawers keep the original verbatim text — the index is a subset, but nothing is lost. → AAAK Dialect & Closets

M

Matryoshka Representation Learning (MRL)
A training technique letting an embedding model emit useful vectors at any dimensionality. EmbeddinggemmaONNX truncates its 768-dim output to 384-dim to be a drop-in ChromaDB replacement. → Internationalization
MCP (Model Context Protocol)
A JSON-RPC 2.0 request/response interface over stdio that lets Claude Code and Claude Desktop invoke MemPalace's ~29 tools without network round-trips, so an agent can live inside the palace. → MCP Server & Tools
Mega-file split
Large source files are chunked into many ~800-char drawers rather than embedded whole, so retrieval is fine-grained and a single big file never dominates the index. Closets point back to the originating file. → Project Mining
Method of Loci
The ancient “memory palace” mnemonic of placing items in imagined spatial locations. MemPalace maps it onto concrete data structures — wings, rooms, drawers — combined with Zettelkasten indexing. → The Palace Model
Mining modes
Three ingestion paths: Projects (code/docs), Convos (chat exports, optional auto-classification), and Extract (binary office documents). Each feeds a specialized miner with its own chunking and metadata strategy. → CLI & Onboarding

N

Never-silent-fallback
When an LLM is unavailable or fails, the system always falls back to its heuristic/regex baseline and records what happened. No data is discarded silently; the user is informed. → LLM Integration
Non-Latin Word Boundaries
Locales with combining-mark scripts (Devanagari, Arabic, Thai, Khmer) declare boundary_chars that replace Python's \b with a lookaround boundary preserving the marks, so a name like अनीता matches in full instead of truncating. → Entity System
NORMALIZE_VERSION
A schema-versioning constant (v2) that gates incremental ingest and auto-purges pre-v2 drawers on a schema bump, preventing mixed old/new rows in the same source. → Conversation Mining
Normalization
Format auto-detection and conversion of 7+ diverse chat export schemas into a canonical >-prefixed transcript, with noise stripping and tool-result truncation. → Conversation Mining

O

Origin (corpus origin)
Whether a corpus is AI-dialogue (Claude/ChatGPT/Slack exports) or human narrative, decided by the two-tier corpus-origin detector. Origin context reclassifies persona-matched candidates and steers downstream entity and mining behavior. → Entity System

P

PalaceRef
A value object identifying a palace: id (cache key), optional local_path (filesystem), and optional namespace (server-mode routing). Replaces legacy path-string arguments under RFC 001. → Storage Backends
Pass 0
Corpus-origin detection run during init: Tier 1 regex heuristics (always, no API) plus optional Tier 2 LLM refinement for platform/persona extraction, classifying whether the corpus is AI-dialogue. → CLI & Onboarding
Per-target PID Guard
Atomic slot-based deduplication in ~/.mempalace/hook_state/mine_pids/ using O_CREAT|O_EXCL and per-target hash digests to prevent concurrent mines of the same target; stale PIDs are detected by age. → Hooks & Auto-save
PreCompact (precompact hook)
A Claude Code event fired right before context compression; it always runs a synchronous mine to capture transcript data before the model loses its detailed context. → Hooks & Auto-save
Preference extraction
16 regex patterns that detect how users express preferences (I've been having trouble with X, I prefer Y); synthetic documents bridge the vocabulary gap between question phrasing and session text. → Benchmarks
Privacy by architecture
The system physically cannot phone home: no telemetry, no analytics. Mining, search, embedding, and LLM calls default to local-only, and endpoint locality is verified by URL parsing; external providers require explicit configuration. → Security & Privacy
Prompt contamination mitigation
A four-stage extraction pipeline in query_sanitizer.py that recovers user intent from queries polluted by prepended system prompts, restoring retrieval that would otherwise collapse (89.8% → 1.0% failure without it). → Security & Privacy
Provenance fields
Optional knowledge-graph fields (source_drawer_id, adapter_name, source_closet, source_file) recording where a fact came from — the drawer, the adapter, or the file/closet that referenced it. → Temporal Knowledge Graph
Provider abstraction
Three provider classes (OllamaProvider, OpenAICompatProvider, AnthropicProvider) share a common interface (classify, check_available, is_external_service) to normalize JSON-mode requests across vendors. → LLM Integration

Q

QueryResult / GetResult
Typed frozen dataclasses that replace Chroma's raw dict returns. They preserve the outer query dimension even when hits are empty, expose a dict-protocol shim for legacy callers, and keep embeddings as None unless explicitly requested. → Storage Backends

R

Recall@k vs QA accuracy
Recall@k measures whether the correct session is in the top-K results; QA accuracy measures whether an LLM generates a correct answer. They are independent metrics — MemPalace's headline 96.6% is R@5, not end-to-end accuracy. → Benchmarks
RFC 002 source adapters
A pluggable ingestion contract (BaseSourceAdapter) for third-party sources (Cursor, GitHub, Slack APIs) with declared transformations, a metadata schema, and a privacy class. → Conversation Mining
Room
A time-based or topic-based grouping within a wing (e.g. diary, meetings, design-docs), detected from file paths, filenames, or keywords during mining. Rooms can span multiple wings via tunnels. → The Palace Model
Room detection
Content-aware routing that assigns each file to a room by folder path (highest priority), filename, or keyword scoring in the first ~2,000 chars, falling back to general if nothing matches. → Project Mining

S

Script-Aware Boundary
A regex lookaround — (?<=[chars])(?=[^chars]) — that treats declared character ranges (e.g. Devanagari U+0900–U+097F) as word-internal, preserving combining marks and multi-codepoint names. → Internationalization
Silent Mode
The default (v3.3.0+) hook behavior: it saves directly via the Python API without returning decision:block, so the user sees only a systemMessage notification and the chat window is never interrupted. → Hooks & Auto-save
Stdio Protection
Redirecting stdout to stderr at the Python and file-descriptor (os.dup2) level before heavy imports, so transitive dependencies (chromadb, onnxruntime) can't print banners that corrupt JSON-RPC payloads. → MCP Server & Tools
Stop Hook
A Claude Code event fired after each assistant response; it counts human messages in the transcript and triggers auto-save once a threshold (SAVE_INTERVAL=15) is reached. → Hooks & Auto-save
Sweep
A timestamp-coordinated, idempotent message-level pass that catches messages missed by file-level chunking, using a cursor and deterministic sweep_SESSION_UUID IDs to resume cleanly after a crash. → Conversation Mining
Symlink defense
Defense-in-depth file I/O hardening: O_NOFOLLOW on POSIX and a pre-check on Windows refuse to follow pre-placed symlinks during export, closing the TOCTOU window before redirected writes can hit system directories. → Security & Privacy

T

Tier 6a content dating
Automatic date extraction from filename, YAML frontmatter, content body, or mtime — in that priority order — populating content_date so closet pointers can carry date:line locators. → Project Mining
Timeline
A chronologically sorted view of facts for an entity or across the whole KG, ordered by valid_from (NULL last), capped at 100 rows — useful for narrative reconstruction. → Temporal Knowledge Graph
Triple (RDF-style)
A fact expressed as subject→predicate→object (e.g. Alice → works_at → Acme Corp), the core KG unit; predicates are normalized to lowercase with underscores. → Temporal Knowledge Graph
Tunnel
An explicit cross-wing link between two rooms (or synthetic topic:/entity: rooms), stored in tunnels.json. User-created tunnels are explicit; topic and entity tunnels auto-generate when shared topics/entities appear across wings. → The Palace Model
Two-pass assistant retrieval
For questions about what the assistant said: pass 1 finds top-5 sessions using user turns only; pass 2 re-indexes those sessions with full text (user + assistant) to avoid diluting the global index. → Benchmarks
Two-Signal-Category Rule
A person must show signals from two different categories (dialogue, action, pronoun, direct-address) to be confidently classified; single-category hits are downgraded to uncertain, so a syntactic pattern like “Click, click, click…” isn't mistaken for a person named Click. → Entity System

U

UTF-8 encoding hardening
Windows stdio reconfiguration to UTF-8 with per-stream error policies (strict on server, replace on CLI) and surrogateescape on stdin, so malformed bytes survive without a UnicodeDecodeError. → Security & Privacy

V

Validity window
Optional valid_from/valid_to timestamps defining when a KG fact is true (ISO-8601 dates or canonical UTC datetimes). NULL means unbounded; both ends are inclusive — the basis of the temporal knowledge graph. → Temporal Knowledge Graph
Verbatim
The non-negotiable storage rule: drawer content is stored exactly as the user said it — never summarized, paraphrased, or lossily compressed — down to whitespace and formatting. Summaries live only in closets, which point back to the verbatim text. → System Architecture
Virtual line numbering
Line numbers added at read time (not stored on disk) when a drawer is retrieved, letting Tier 6a closet pointers jump to a specific line range without rewriting the stored text. → Project Mining

W

Wake-up context
L0 (identity from ~/.mempalace/identity.txt) plus L1 (top importance-scored drawers) injected at agent startup — ~600–900 tokens of critical facts without burning the full context window. → CLI & Onboarding
Wing
A named broad category (person, project, department) derived from a directory name and normalized to lowercase with underscores. Drawers tagged with a wing can be filtered, scoped, or tracked as a unit; it is the top level of the palace tree. → The Palace Model
Wing Derivation
How hooks infer a project's wing name from a JSONL transcript: cwd metadata, then an encoded .claude/projects/ path, then a legacy -Projects- segment, defaulting to wing_sessions. → Hooks & Auto-save
Wing resolution
Heuristic routing that auto-defaults conversation files from .claude/projects, .codex, or .gemini to wing_api, with dirname-based slugification as fallback for other sources. → Conversation Mining
Write-Ahead Log (WAL)
A JSONL audit trail at ~/.mempalace/wal/write_log.jsonl recording all drawer/KG mutations (with content redaction) for review and rollback. → MCP Server & Tools

Z

Zettelkasten Index
Niklas Luhmann's slip-box method mapped onto MemPalace: small cross-referenced cards (closets) point to larger verbatim source material (drawers). The AAAK format makes a card scannable in one LLM context window, so the system can decide which drawer to open without loading it. → AAAK Dialect & Closets
